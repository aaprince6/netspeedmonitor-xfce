# Changelog

All notable changes to NetSpeedMonitor XFCE are documented here.

## [1.0.0] - 2026-11-03

### Added
- Initial XFCE Generic Monitor implementation.
- Combined receive/transmit rates across eligible physical adapters.
- Automatic adapter discovery through `/sys/class/net`.
- B/s, KB/s and MB/s formatting.
- Colored download/upload indicators and hover tooltip.
- Install and uninstall scripts.
- Documentation and MIT license.
