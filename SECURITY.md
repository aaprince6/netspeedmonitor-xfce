# Security Policy

## Supported versions

Security fixes are currently intended for the latest version on the `main` branch. Please use the latest release when possible.

## Reporting a vulnerability

Please do not publish security vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** feature on this repository (the Security tab) to send a private report. Include:

- A clear description of the issue and its potential impact.
- Steps to reproduce, including the affected version or commit.
- Any relevant logs or proof-of-concept details, with private information removed.

Please allow maintainers reasonable time to investigate and prepare a fix before public disclosure.

## Scope

NetSpeedMonitor XFCE is a local Bash script intended to run as the logged-in user. It does not need root privileges, collect telemetry, or send network data to external services. Please report vulnerabilities involving the script, installer, uninstaller, or project distribution.
